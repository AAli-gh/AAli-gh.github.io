# قالب فروشگاه لوازم یدکی (HTML + Tailwind + Alpine)

این پکیج شامل صفحات اصلی یک فروشگاه اینترنتی است:
- صفحه اصلی، محصولات، دسته‌بندی‌ها
- جزئیات محصول + نظرات
- وبلاگ و پست وبلاگ
- پروفایل کاربر (داشبورد، سفارش‌ها، آدرس‌ها، علاقه‌مندی‌ها، تنظیمات)
- سبد خرید، تسویه حساب، پیگیری سفارش
- ورود/ثبت‌نام، درباره ما، تماس با ما، سؤالات متداول، قوانین مرجوعی، ۴۰۴

## اجرای سریع
فقط فایل `index.html` را در مرورگر باز کنید. Tailwind و Alpine از CDN بارگذاری می‌شوند.

## سفارشی‌سازی
- رنگ‌های برند در tailwind.config CDN بالای هر صفحه تعریف شده (primary و accent).
- فونت Vazirmatn از Google Fonts بارگذاری شده.
- هدر/فوتر ثابت‌اند؛ در پروژه واقعی می‌توانید با template engine جدا کنید.
