مرور کلی

هدف این پروژه ساخت یک پایپ‌لاین کامل برای پیش‌بینی حرکت قیمت بیت‌کوین از روی داده‌های تاریخی بود: از دریافت و پاک‌سازی داده تا ساخت ویژگی، آموزش مدل و ارزیابی صادقانه با اعتبارسنجی زمانی.

تمرکز اصلی روی درست ارزیابی کردن بود، نه صرفاً بالا بردن یک عدد؛ چون در سری‌های زمانی مالی، ساده‌ترین اشتباه‌ها (مثل نشت داده) نتیجه‌های بسیار خوش‌بینانه می‌سازند.

پایپ‌لاین

  1. 01 — data

    دریافت و پاک‌سازی داده

    داده‌های OHLCV روزانه، حذف مقادیر ناقص و یکسان‌سازی بازهٔ زمانی با Pandas.

  2. 02 — features

    Feature Engineering

    بازده، نوسان، میانگین‌های متحرک و ویژگی‌های تأخیری؛ همه فقط با اطلاعات تا لحظهٔ t.

  3. 03 — model

    مدل‌سازی

    مقایسهٔ یک baseline ساده با مدل‌های مبتنی بر درخت (Gradient Boosting) با Scikit-learn.

  4. 04 — evaluation

    ارزیابی

    اعتبارسنجی با TimeSeriesSplit و گزارش MAE / RMSE نسبت به baseline.

نمونه کد

هستهٔ ساخت ویژگی و اعتبارسنجی زمانی (نسخهٔ ساده‌شده).

pipeline.py 
import pandas as pd
from sklearn.ensemble import GradientBoostingRegressor
from sklearn.model_selection import TimeSeriesSplit
from sklearn.metrics import mean_absolute_error

df = pd.read_csv("btc_daily.csv", parse_dates=["date"]).set_index("date")

# Feature engineering — only information available at time t
df["ret_1d"] = df["close"].pct_change()
df["sma_7"]  = df["close"].rolling(7).mean()
df["vol_14"] = df["ret_1d"].rolling(14).std()
df["target"] = df["close"].shift(-1)          # next-day close
df = df.dropna()

X, y = df[["ret_1d", "sma_7", "vol_14"]], df["target"]

scores = []
for train, test in TimeSeriesSplit(n_splits=5).split(X):
    model = GradientBoostingRegressor(random_state=42)
    model.fit(X.iloc[train], y.iloc[train])
    scores.append(mean_absolute_error(y.iloc[test], model.predict(X.iloc[test])))

آموخته‌ها

  • یک baseline ساده (مثلاً «قیمت فردا = قیمت امروز») معیار واقعی موفقیت است.
  • اعتبارسنجی تصادفی در سری زمانی گمراه‌کننده است؛ تقسیم باید زمانی باشد.
  • پیچیدگی مدل کمتر از کیفیت ویژگی‌ها و صحت ارزیابی اهمیت دارد.
